## Accessibility Guidelines for Diagrams

All images in this directory should include proper alt text and descriptions for accessibility:

- **Alt text**: Concise description of the image content (under 125 characters)
- **Long descriptions**: Detailed explanations for complex diagrams in image captions
- **Color contrast**: Minimum 4.5:1 ratio for readability
- **Text size**: Sufficiently large to read when images are displayed at recommended sizes

### Example Image Usage in MDX:

```md
![Isaac Sim Architecture](/img/isaac-sim-arch.png "Architecture diagram showing Isaac Sim components: Omniverse Kit, PhysX engine, RTX renderer, and ROS bridge")
```

### Recommended Alt Text Patterns:
- For architecture diagrams: "[Component] architecture diagram showing [key elements]"
- For pipeline diagrams: "[Pipeline name] workflow with [number] stages"
- For comparison diagrams: "Comparison between [item A] and [item B]"
- For process diagrams: "[Process name] process flow with [key stages]"
