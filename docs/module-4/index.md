# Module 4: VLA Robotics & Capstone

This module covers Vision-Language-Action models, voice command integration, and the capstone autonomous humanoid project.

## Overview

This final module brings together all concepts learned throughout the textbook into an integrated system using Vision-Language-Action (VLA) models. You'll learn to:

- Integrate voice command recognition with robotics systems
- Create AI action planners that translate high-level commands to robot actions
- Implement complete autonomous humanoid systems
- Deploy integrated systems on physical hardware

## Learning Objectives

By the end of this module, you will be able to:

- Integrate Whisper speech recognition with robotics systems
- Create LLM-based action planners for ROS 2
- Implement Vision-Language-Action models for robotics applications
- Execute the complete capstone autonomous humanoid project

## Module Structure

- Chapter 1: Whisper Voice Commands - Integrate speech recognition with robotics
- Chapter 2: LLM → ROS 2 Action Planner - Create AI-driven action planning
- Chapter 3: Capstone — Autonomous Humanoid - Complete integrated project
